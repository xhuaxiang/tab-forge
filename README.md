## ✨ 功能概览

| 功能 | 说明 |
|------|------|
| ✅ **六线谱编辑** | 支持添加/删除小节，在各弦各品添加音符 |
| ✅ **预设调弦** | Standard、Drop D、Open G 等 6 种预设，也支持手动输入 |
| ✅ **Web Audio 播放** | 浏览器直接合成吉他音色播放乐谱 |
| ✅ **录音** | 通过麦克风录制音频（为后续 AI 扒谱分析准备） |
| ✅ **导出** | 支持 **ASCII TAB 文本** 和 **JSON** 格式导出 |
| ✅ **国际化** | 中文 / 英文 界面 |
| ✅ **持久化存储** | 乐谱自动保存到浏览器本地存储 |

## 🔧 安装方法

### 开发模式安装（推荐）

```bash
# 1. 在项目根目录安装依赖
pnpm install

# 2. 构建 TabForge 扩展
pnpm build

# 3. 加载到 Chrome
#    - 打开 Chrome → chrome://extensions
#    - 开启「开发者模式」
#    - 点击「加载已解压的扩展程序」
#    - 选择 extensions/TabForge/dist 目录
```

### 从源码运行开发模式

```bash
# 在项目根目录执行
pnpm install

# 进入 TabForge 目录启动开发服务器
pnpm dev
```

## 🚀 快速入门

1. 点击 Chrome 工具栏的扩展图标 ![icon](public/icon/icon.png) 打开 TabForge
2. 点击 **「+ 添加小节」** 创建一个空白小节
3. 在 **「音符编辑」** 区域输入弦号和品位
   - 例：弦号 `1`（高音 E 弦），品位 `0`（空弦）
   - 点击 **「添加音符」**
4. 此时六线谱已显示内容，点击 **「▶ 播放」** 试听
5. 点击 **「导出」** Tab 页，选择 **「TAB 文本」** 或 **「JSON」** 导出

## 📖 操作指南

### 1. 创建乐谱

| 操作 | 方法 |
|------|------|
| **添加小节** | 点击 **[+ 添加小节]** 按钮，每点击一次新增一个空白小节 |
| **删除小节** | 点击 **[− 删除小节]** 删除最后一个小节 |
| **清空乐谱** | 点击 **[🗑 清空]** 确认后删除所有小节 |

> **提示**：乐谱内容会自动保存在 Chrome 本地存储中，关闭扩展后重新打开数据不会丢失。

### 2. 添加音符

**吉他六线谱基础**：六线谱从下到上共 6 根线，对应吉他的 6 根弦：

```
e ─── 1弦 (高音E，最细)
B ─── 2弦
G ─── 3弦
D ─── 4弦
A ─── 5弦
E ─── 6弦 (低音E，最粗)
```

**添加音符步骤**：

1. 确保已有小节（如没有，先点「+ 添加小节」）
2. 在 **「音符编辑」** 区域设置参数
3. 点击 **「添加音符」**

**参数说明**：

| 参数 | 范围 | 说明 |
|------|------|------|
| **弦号** | 1 ~ 6 | 1 = 高音E弦（最细），6 = 低音E弦（最粗） |
| **品位** | 0 ~ 24 | 0 = 空弦，1~24 = 按住的品数 |
| **时值** | 多种 | 全音符 / 二分 / 四分 / 八分 / 十六分音符 |

**添加多个音符**：重复添加即可，所有音符会在同一小节中依次排列。

> **示例**：演奏 C 大调音阶
> - 5弦3品 (C) → 4弦0品 (D) → 4弦2品 (E) → 4弦3品 (F)
> - 3弦0品 (G) → 3弦2品 (A) → 2弦0品 (B) → 1弦0品 (C)

### 3. 调弦设置

**预设调弦**：从下拉菜单选择

| 预设名称 | 调弦 (6弦 → 1弦) | 说明 |
|----------|-------------------|------|
| **Standard** | E2 A2 D3 G3 B3 E4 | 标准调弦 |
| **Drop D** | D2 A2 D3 G3 B3 E4 | 6弦降全音到 D |
| **Open G** | D2 G2 D3 G3 B3 D4 | 开放 G 和弦调弦 |
| **Open D** | D2 A2 D3 F#3 A3 D4 | 开放 D 和弦调弦 |
| **Half Step Down** | Eb2 Ab2 Db3 Gb3 Bb3 Eb4 | 降半音调弦 |
| **Full Step Down** | D2 A2 D3 F#3 A3 D4 | 降全音调弦 |

**手动调弦**：直接修改 6 个调弦输入框，支持标准音名格式如 `E4`、`B3`、`D#4` 等。

> **注意**：调弦会影响播放时的音高合成，请确保与实际乐器一致。

### 4. 播放乐谱

| 按钮 | 功能 |
|------|------|
| **▶ 播放** | 从当前乐谱开头播放，再次点击变为「暂停」 |
| **⏹ 停止** | 停止播放，回到开头 |
| **▶ 继续** | 暂停后继续播放 |

**播放原理**：
- 使用 Web Audio API 在浏览器中合成吉他音色
- 波形使用三角波（`triangle`）配合音量包络模拟拨弦效果
- 根据调弦和品位自动计算正确音高

> **提示**：在播放状态下，状态栏会显示当前播放到第几个小节。

### 5. 导出乐谱

点击 **「导出」** Tab 标签打开导出面板。

**导出格式**：

| 格式 | 说明 | 使用场景 |
|------|------|----------|
| **TAB 文本** | 纯文本 ASCII 格式六线谱 | 分享到论坛、聊天、社交媒体 |
| **JSON** | 结构化数据，包含所有音符信息 | 程序处理、备份、二次开发 |

**示例 - ASCII TAB 文本输出**：
```
============================================================
  Untitled
  BPM: 120  |  Tuning: E2 A2 D3 G3 B3 E4
============================================================

e|02-03-05-|07-08-10-|
B|--------|---------|
G|--------|---------|
D|--------|---------|
A|--------|---------|
E|--------|---------|
```

**操作方法**：
1. 点击「TAB 文本」或「JSON」切换显示格式
2. 点击「📋 复制到剪贴板」复制内容
3. 粘贴到任意文本编辑器保存
